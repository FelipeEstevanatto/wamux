# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub's
[Security Advisories](https://github.com/FelipeEstevanatto/wamux/security/advisories/new)
(the **Report a vulnerability** button on the repository's *Security* tab).
Include:

- the affected version (the `VERSION` file, or `system.version` from
  `GET /server/stats`),
- a description and, if possible, a minimal reproduction,
- the impact you believe it has, and any suggested fix.

You will get an acknowledgement as soon as possible, and a reasonable window is
expected before any public disclosure.

## Supported versions

Only the latest release receives security fixes.

## Scope

WaMux is an unofficial, self-hosted WhatsApp client built on
[whatsmeow](https://github.com/tulir/whatsmeow). Reports about WhatsApp or Meta
themselves, or about using the software in violation of WhatsApp's terms, are
out of scope.
